# IBA Estúdio

Site institucional da IBA Estúdio. SPA em React + Tailwind CSS + Framer Motion.

## Desenvolvimento

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Gera a versão de produção em `dist/`.

## Estrutura

- `src/pages/` — páginas (Home, Serviços, Sobre, Contato, Políticas)
- `src/components/` — Header, Footer, WhatsApp flutuante, Reveal, ícones
- `src/lib/site.js` — constantes (WhatsApp, e-mail) e helpers de link
- `public/img/` — favicon e logo oficial
